# 🏛️ नगर पालिका सुमेरपुर आम चुनाव 2026 | कंट्रोल रूम पोर्टल

**कार्यालय रिटर्निंग ऑफिसर (उपखण्ड मजिस्ट्रेट), सुमेरपुर (पाली, राजस्थान)**

यह एक फुल-स्टैक, मल्टी-पेज, डेटाबेस-संचालित और रियल-टाइम वेब पोर्टल है जो चुनाव दिवस पर 35 वार्डों, 36 बूथों और 6 जोनों के लाइव मतदान डेटा प्रबंधन, ऑपरेटर एंट्री, टाइम-विंडो लॉकिंग, सांख्यिकी रिपोर्टिंग और बिग-स्क्रीन LED डिस्प्ले के लिए बनाया गया है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

1. **💾 SQLite डेटाबेस बैकएंड (`election_sumerpur.db`)**:
   - सभी 36 मतदान केंद्रों और 6 जोनों का डेटा स्वचालित रूप से स्थायी डेटाबेस में सुरक्षित होता है।
   - वार्ड 26 (बूथ 27) निर्विरोध निर्वाचन (श्रीमती वीणा देवड़ा - BJP) को स्वतः अलग रखता है।

2. **⚡ रियल-टाइम लाइव सिंक (Server-Sent Events)**:
   - किसी भी ऑपरेटर द्वारा अपने मोबाइल या कंप्यूटर से वोट दर्ज करते ही RO मास्टर डैशबोर्ड और LED स्क्रीन बिना पेज रिफ्रेश किए तुरंत अपडेट हो जाती है।

3. **📑 7 विशिष्ट पेजेस / व्यूज**:
   - **📊 RO मास्टर डैशबोर्ड (`/` या `#dashboard`)**: टर्नआउट ग्राफ (Chart.js), स्लॉट विश्लेषण, हाई/लो अलर्ट।
   - **📋 36 बूथ मॉनिटर (`#booths`)**: सर्च एवं ज़ोन/वार्ड फ़िल्टर सहित पूर्ण तालिका, CSV डाउनलोड।
   - **✍️ ऑपरेटर डेटा एंट्री (`#entry`)**: मोबाइल-अनुकूलित फॉर्म, 30-मिनट टाइम-लॉक विंडो, स्वतः गणना।
   - **🗺️ ज़ोनल मजिस्ट्रेट निर्देशिका (`#zones`)**: एरिया व जोनल मजिस्ट्रेट संपर्क नंबर (क्लिक-टू-कॉल `tel:` सुविधा)।
   - **📄 शासकीय PDF रिपोर्ट्स (`#reports`)**: 10 AM, 1 PM, 3 PM, 6 PM, कतार व फाइनल रिपोर्ट का प्रिंट/PDF जनरेटर (हस्ताक्षर ब्लॉक सहित)।
   - **📺 बिग-स्क्रीन LED डिस्प्ले (`#livedisplay`)**: कंट्रोल रूम LED/प्रोजेक्टर हेतु हाई-कंट्रास्ट डार्क मोड।
   - **⚙️ RO एडमिन कंट्रोल (`#admin`)**: टाइम-लॉक ओवरराइड, ऑडिट लॉग्स एवं रिहर्सल रिसेट।

## 🚀 पोर्टल को शुरू कैसे करें (How to Run)

### 1. लोकल कंप्यूटर पर शुरू करें:
टर्मिनल / कमांड प्रॉम्प्ट में निम्न कमांड चलाएं:
```bash
npm start
```
इसके बाद ब्राउज़र में खोलें:
👉 **`http://localhost:3000`**

---

### 2. कंट्रोल रूम Wi-Fi / LAN पर सभी मोबाइल फोन से कनेक्ट करें:
जैसे ही आप सर्वर शुरू करेंगे, टर्मिनल पर आपका लोकल IP पता दिखेगा (उदा. `http://192.168.1.45:3000`):
1. अपने लैपटॉप/कंप्यूटर और सभी 5 ऑपरेटरों के मोबाइल फोन को एक ही Wi-Fi नेटवर्क (या मोबाइल हॉटस्पॉट) से कनेक्ट करें।
2. सभी ऑपरेटर अपने मोबाइल ब्राउज़र में वह IP पता खोलेंगे (उदा. `http://192.168.1.45:3000`)।
3. वे अपने-अपने ऑपरेटर लॉगिन से सीधे अपने मोबाइल से वोट दर्ज कर सकेंगे।

---

### 3. इंटरनेट पर लाइव होस्ट कैसे करें (Deploy to Cloud / Free Hosting):

यह ऐप **Node.js 18+ / 20+** और **Express** पर आधारित है, इसलिए इसे किसी भी क्लाउड प्लेटफॉर्म पर 1-क्लिक में लाइव किया जा सकता है:

#### विकल्प A: Render.com पर (सर्वोत्तम व आसान)
1. अपने प्रोजेक्ट को GitHub पर पुश करें।
2. [Render.com](https://render.com) पर जाएँ -> **New Web Service** चुनें।
3. **Build Command:** `npm install`
4. **Start Command:** `npm start`
5. **Create Web Service** पर क्लिक करें -> आपको लाइव URL (उदा. `https://sumerpur-election.onrender.com`) मिल जाएगा।

#### विकल्प B: Railway.app पर
1. [Railway.app](https://railway.app) पर नया प्रोजेक्ट बनाएं और GitHub रिपॉजिटरी चुनें।
2. यह `Procfile` को पहचान कर स्वतः लाइव कर देगा।
